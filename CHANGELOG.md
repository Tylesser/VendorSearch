# Changelog

## 1.0.0

- First release.
- Search box on the vendor window that filters the vendor's item grid by item name, type, subtype or equipment slot.
- Paging follows the matching items; matching items keep all the normal vendor actions (right-click to buy, tooltips, linking, preview).
- Match count and "no matches" message; search clears when the vendor closes.
- Fade option: fade non-matching items on the vendor's normal pages instead of hiding them, with the pages that contain matches listed.
- Flip finder (optional, uses Auctionator): vendor items worth clearly more on the auction house get a green border, a "+profit" label and a tooltip line; the Flips option shows only those.
- The match count is shown on the vendor's page line.
- Alt-drag to move the search box, `/vsearch reset` to put it back.
